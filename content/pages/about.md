I build agent tooling — MCP servers, multi-agent workflows, and the small pieces
of plumbing that make coding agents usable day to day. I also do Kaggle
competitions and quantitative work.

This site is where I write in public:

- notes on agent tooling and the tools I build
- competition writeups and what actually moved the leaderboard
- quantitative work, worked through with data rather than opinion
- longer pieces that start as notes and end up worth keeping

The source is Markdown, published as a static site, so the writing stays portable
and the pages stay fast.
